# E-Commerce Business Overview Dashboard

Hi! Welcome to my Power BI project.

I built this interactive dashboard to analyze the sales performance, customer behavior, and overall profitability of an e-commerce business. The main goal of this project is to transform raw business data into clear, actionable insights.

**Dashboard Overview:**

![Main Dashboard](https://github.com/Uday-123-hue/E-Commerce-Business-Overview-PowerBI/blob/main/ALL.png?raw=true)


### Key Insights & Features
* **Monthly Sales Trends:** A timeline analysis from Jan to Dec to identify peak sales seasons.
* **Top Performing Products:** Ranked bar charts highlighting the products that drive the most revenue.
* **Customer Segmentation:** A detailed breakdown of the customer base to understand audience demographics and market reach.
* **Profitability Analysis:** Scatter plot evaluation of profit margins to identify the most valuable customers.
* **Quarterly Growth:** Business performance and momentum tracking across Q1 to Q4.

### Tools & Techniques Used
* **Power BI Desktop:** For building visuals and the interactive navigation menu.
* **Power Query:** For data cleaning and transformation.
* **DAX (Data Analysis Expressions):** For creating custom measures and calculations.

### How to Navigate & Use
I have designed a custom navigation menu at the top of the report. You can easily click on the buttons (Timeline, Rankings, Segments, Drilldown, Margins, Growth, ALL) to switch between different analytical views.

**To interact with it yourself:**
1. Download the E-Commerce Business Overview.pbix file from this repository.
2. Open the file using Power BI Desktop.
3. Use the top navigation tabs to explore the data.
